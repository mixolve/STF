# Source availability

The project currently contains the compiled Apple Silicon REAPER extension only. No matching `.c`, `.cpp`, `.mm`, header, build script, or source directory for Web+OSC was present in `reaper-main/Extensions` or `projects-code/STF/reaper-extensions` when this folder was prepared. This folder preserves a copy of the installed binary; it is not a source backup and cannot be rebuilt from the included files. The source will need to be located separately to make this folder equivalent to the other source packages.
