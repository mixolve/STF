# mixolve_custom-view v30

Расширение REAPER для macOS Apple Silicon (arm64). Исходники и установщик.

## Actions

- `mixolve_custom-view: move` — перемещение выбранного окна до следующего клика.
- `mixolve_custom-view: toggle titlebar + native resize focused` — в одном действии скрывает или возвращает заголовок и штатный ресайз REAPER для выбранного окна.
- `mixolve_custom-view: toggle titlebar + native resize (reaper + fx)` — то же для главного окна REAPER и плавающих FX.
- `mixolve_custom-view: toggle preset panel focused` — управление верхней панелью пресетов выбранного FX.
- `mixolve_custom-view: toggle preset panels (fx)` — управление панелями пресетов всех плавающих FX.

**ID четырёх старых действий и Move сохранены:** переназначать хоткеи не нужно. Отдельное действие `MIXOLVE_CUSTOMVIEW_WINDOWS_NATIVE_RESIZE_TOGGLE` удалено. Окна FX Chain исключены из переключения заголовка и ресайза; отдельное окно Monitoring FX обрабатывается.

## Заголовок и штатный ресайз

При скрытии заголовка в одном вызове `NSWindow.styleMask` удаляются `Titled`, `FullSizeContentView` и `Resizable`. При восстановлении возвращается исходная маска стилей окна из snapshot. Ни отдельного ресайз-экшена, ни блокировки геометрии (`minSize/maxSize`), ни перехвата мыши и `NSWindow.delegate` нет. Сам `contentView` плагина не заменяется. Изменения размеров, которые плагин запрашивает программно, намеренно не перехватываются.

**Ограничение:** конкретный плагин или REAPER может зависеть от флага `Resizable` и для внутреннего ресайза. Работа на macOS с конкретным плагином здесь не проверялась. Не используйте сборку без предварительной проверки интерфейса плагина. 

## Установка

Закройте REAPER, распакуйте архив и выполните в папке проекта:

```bash
bash install_macos.command
```

Установщик компилирует `reaper_mixolve_custom-view.dylib` для arm64, создаёт резервную копию установленной библиотеки и копирует новую в каталог UserPlugins, указанный в скрипте или через `REAPER_USERPLUGINS_DIR`. После установки перезапустите REAPER.

## Панель пресетов

Скрытие панели пресетов реализовано без замены исходного `NSWindow.contentView`. Индивидуальное и глобальное состояние пресетов сохраняется в REAPER ExtState; при неизвестной структуре интерфейса скрытие не выполняется.
